Old loader model: every obfuscation approach that uses load() can be defeated by hooking load globally and printing its argument. One line of Lua reveals the decoded source regardless of how many XOR/byte-array layers wrapped it.

VM mode: the JavaScript compiler turns the script into a custom instruction stream. The final Lua output contains an interpreter, a deserializer, captured closure state, and the encoded instruction stream. The original source is never passed into the VM runtime. There is no load() call on source anywhere. A hook on load sees the VM booting — not your script.

To analyze VM mode, a reverser has to understand the custom instruction set, decode the bytecode container, follow the VM dispatch loop, and reconstruct the original control flow and data operations. That's a multi-hour job even for skilled reversers.
