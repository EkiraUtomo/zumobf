17-layer Lua obfuscator built for Roblox scripts. All heavy work runs in a Web Worker so the UI never freezes. Each layer addresses a specific attack vector:

🔑
Polymorphic XOR key
Key derived at runtime via (A×B)%251+offset — no plaintext key in source
🔀
Opaque predicates
Guards real code behind conditions that are always true but statically undecidable
✂️
String chunk split
Every string shredded into random fragments — no complete literal exists in source
🖥️
Micro-VM dispatch
Code wrapped in an opcode table walked by a PC — control flow reconstruction nightmare
🪤
Anti-extraction trap
Fingerprints _G size — decoder returns garbage if run outside Roblox environment
📦
Triple-load nesting
Three shells: reverse-byte, XOR, byte-array — each using a different strategy
