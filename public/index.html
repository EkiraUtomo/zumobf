Previous ceiling: every obfuscation approach that uses load() can be defeated by hooking load globally and printing its argument. One line of Lua reveals the decoded source regardless of how many XOR/byte-array layers wrapped it.

VM mode: your script is compiled to a custom 39-opcode bytecode format by a JavaScript compiler. The output contains a Lua virtual machine (~150 lines) and an obfuscated bytecode number array. There is no load() call on source anywhere. A hook on load sees the VM booting — not your script.

To reverse VM mode, an attacker must: understand the VM instruction set, reverse the rolling-XOR bytecode decryption, deserialize the custom proto format, reconstruct the control flow from opcodes, and then figure out what the reconstructed logic does. That's a multi-hour job even for skilled reversers.
